01 / Plugins

不是等功能。
是把业务写成插件。

使用 Python 或 JavaScript，将业务规则、外部接口与机器人动作封装为可调试、可复用的插件。

  1. 01
    ⌘

    编写

    选择 Python、JavaScript 或兼容 ATM 的写法，使用 Bucket、权限、多轮输入、主动推送与插件 Webhook。

  2. 02
    ↯

    调试

    在调试页验证触发和输出，借助 AI 辅助编写，并通过行级 diff 检查实际变更。

  3. 03
    ✓

    运行

    保存后尝试热重载，继续由规则或 Webhook 触发；结果可在面板和日志中确认。

  • Python
  • JavaScript
  • ATM 兼容
  • Bucket
  • 权限控制
  • 多轮输入
  • 主动推送
  • Webhook

  • 入站 Token

04 / AI Brain

不是接入一个模型。
是编排整套智能能力。

让触发、模型、工具与知识协同运行，再将结果回复到当前会话，或推送到已支持推送的渠道。

  1. 01触发

    对话 · AI 定时 · 工作流

  2. 02模型路由

  3. 03能力调用

    技能 · MCP · 知识库

  4. 04交付

    回复 · 支持的渠道推送 · Bot-Chat

Intelligence stack

让 AI 从回答，走向执行。

  • 技能可由 URL、GitHub 或技能市场导入，并与 MCP 工具组合。

  • 知识来源包括文本、文件、URL 与 `.bbotkb`，需要时由 Bot-Chat 人工接管。

Deploy

用 Docker，开始运行。

启动后打开 Web 管理台，挂载数据目录即可持久化插件、适配器、脚本与 AI 配置。

镜像
241793/b-bot:latest
Web 面板
5000
数据目录
/app/mount
Terminal 
docker run -d \
  --name bbot \
  --restart unless-stopped \
  -p 5000:5000 \
  -p 8888:8888 \
  -v /var/run/docker.sock:/var/run/docker.sock \
  -v /your/data/path:/app/mount \
  241793/b-bot:latest

容器管理权限

命令中的 docker.sock 挂载用于容器管理，会授予 B-BOT 容器访问宿主 Docker 守护进程的能力。仅在受控主机上部署。

部署完成后，浏览器打开 http://服务器IP:5000。
